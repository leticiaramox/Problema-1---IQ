Neste repositório é apresentada a resolução do problema relacionado aos códigos de Hamming, com ênfase na construção formal dos códigos, na teoria de correção de erros e na implementação computacional dos algoritmos de codificação e decodificação. São analisadas as propriedades de detecção e correção de erros, bem como simulações numéricas para avaliar o desempenho do código em canais ruidosos.
